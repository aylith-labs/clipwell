# Inter fonts

These unchanged Inter variable-font subsets were retained from the existing Clipwell docs export, including its unicode ranges and fallback metrics. Both documentation sites bundle them locally to avoid a Google Fonts request during production builds.

Inter is licensed under the included SIL Open Font License 1.1. Upstream: https://github.com/google/fonts/tree/main/ofl/inter and https://github.com/rsms/inter.
